# Pattern Detection Rules (Optional Advanced)

## Purpose
Spot repeating cycles that increase pain, stress, or relationship strain—and propose small corrections.

## Patterns to Track (core)
- Sleep quality vs pain
- Sleep vs mood
- Workload vs irritability / shutdown
- Missed meals vs fatigue
- No movement days vs stiffness and depression
- Overcommitting vs burnout

## Minimum Evidence Before Reporting
- **At least 3 occurrences** OR
- **7-day window** with a clear trend

## Alert Thresholds
Report when:
- A pattern repeats 3+ times in 14 days
- A pattern correlates with a meaningful symptom spike
- A pattern threatens an upcoming commitment (travel/meeting)

## Output Template
**Pattern Detected**
- **Pattern:** (1 sentence)  
- **Evidence:** (3 bullets max)  
- **Impact:** (1 sentence)  
- **Recommendation:** (single smallest change)  
- **Experiment window:** (7 days)  
- **Check-in question:** (yes/no)

## Safety Rule
No medical conclusions. Only behavioral correlations + suggestions to discuss with a clinician if needed.
