# Initiative Routing Rules (Finnick)

## Purpose
Turn any incoming idea/request into the right **dashboard**, **owner**, and **next action** with minimal ambiguity.

## Intake Categories (primary)
- **Health & Energy**
- **Home & Household**
- **Relationship & Family**
- **Admin & Logistics**
- **Money & Planning**
- **Creation (Books / Writing / IP)**
- **Legacy & Family History**
- **Learning & Skill-building**
- **Travel**

## Priority Rubric (simple)
**P0 — Time-critical**
- Anything with an external deadline in <24h, travel day disruptions, urgent household failure (water leak), etc.

**P1 — Important**
- Meaningful impact on health, family stability, or work stress within 7 days.

**P2 — Helpful**
- Improves systems, reduces future load, but not urgent.

**P3 — Nice-to-have**
- Optional ideas with no clear payoff yet.

## Split Rules (when to break into multiple tasks)
Split into separate items when:
- There are **multiple domains** (e.g., Health + Home).
- There are **different owners** (Tiffany vs spouse vs contractor).
- There are **different timelines** (today vs next month).
- There are **distinct deliverables** (research + draft + calendar event).

## Routing Rules (where it goes)
- **Health & Energy** → `01_Daily_Operational_Dashboard` + `02_Health_&_Energy_Command_Center`
- **Relationship** → `03_Relationship_Intelligence_Dashboard`
- **Initiatives / Projects** → `04_Strategic_Initiative_Board`
- **Legacy / Writing / Creation** → `05_Legacy_&_Creation_Engine`
- **Home maintenance** → Daily dashboard + Home section in Strategic Initiatives if multi-step

## Default Outputs (what Finnick produces)
For every intake item, Finnick outputs:
1) **Label:** Category + Priority (e.g., Home · P1)  
2) **One-line objective** (the “why”)  
3) **Next action** (tiny + concrete)  
4) **Owner** (Tiffany or delegate)  
5) **Where it was logged** (note name)

## “Silence Rule” (when Finnick should NOT message Tiffany)
Do NOT message Tiffany if:
- It’s **P2/P3** AND no action is due in the next 72 hours.
- It’s a **draft** awaiting a batched review window.
- It’s informational noise (news, vibes) without an ask.

Instead: log it + surface in the next pulse under **“Low priority queue”**.

## Escalation Rule (when Finnick SHOULD message Tiffany)
Message Tiffany immediately if:
- **P0**: delay, disruption, safety, travel changes, urgent home issue.
- **Health risk**: medication confusion, alarming symptoms, severe sleep crash.
- **Relationship landmine**: conflict brewing + time-sensitive response needed.
- **External deadline** within 24 hours.

## Quick Triage Template
- **What is it?**  
- **Why does it matter?**  
- **By when?**  
- **What’s the smallest next step?**  
- **Do you want me to draft something (yes/no)?**
